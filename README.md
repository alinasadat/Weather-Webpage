# Chicago Weather Now

A simple responsive, client-side weather webpage fixed to Chicago, Illinois.

## Features
- Always displays Chicago weather
- Current temperature in °F
- Coat/umbrella recommendation using the current hour plus the next three hours
- UV index with five text levels
- Wind speed in mph
- Responsive desktop/mobile layout
- No browser location permission
- No API key and no custom server required

## GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to the root of a public GitHub repository.

Then open:
**Settings → Pages → Build and deployment → Deploy from a branch**

Choose the `main` branch and `/ (root)`, then save.
